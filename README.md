# 配偶者ビザ 質問書 自動作成システム

ヒアリング画面に入力 → ボタン一発で入管公式書式「質問書」(全8ページ)が完成します。

## 同梱ファイル

| ファイル | 役割 |
|---|---|
| `streamlit_app.py` | ヒアリング画面アプリ本体 |
| `fill_questionnaire.py` | 転記エンジン(JSON→Excel) |
| `master_schema.json` | 全219項目のマスタ定義 |
| `質問書1v.xlsx` | 入管公式書式テンプレート(転記先) |
| `requirements.txt` | 必要ライブラリ |

※ これらのファイルは必ず同じフォルダに置いてください。

## セットアップと起動

```bash
# 1. ライブラリのインストール
pip install -r requirements.txt

# 2. アプリ起動
streamlit run streamlit_app.py

# 3. ブラウザで http://localhost:8501 が自動で開きます
```

## 使い方

1. 左サイドバーで「ケース設定」のチェックを入れる
   (紹介者あり / 再婚 / お子さんあり / 退去強制歴あり など)
   → 該当する質問項目だけが画面に表示されます
2. 各タブ(Sheet1〜8)の項目を入力
3. 下部の「✨ 質問書Excelを作成する」を押す
4. 「📥 質問書Excelをダウンロード」で完成版を保存

入力内容は「💾 入力データをJSON保存」で保存でき、後で再利用できます。

## コマンドラインからの転記(アプリを使わない場合)

```bash
python fill_questionnaire.py 質問書1v.xlsx データ.json 出力.xlsx
```

## 対応している入力方式

- 氏名: フリガナ(上)+漢字(下)の縦積み
- チェックボックス(□→☑): 初婚/再婚、退去強制の有無、違反内容 など
- ○囲み: 結婚式の出席者、結婚を知っている親族、性別 など
- 日付の年月日分割、自由記述ブロック、列幅自動調整
